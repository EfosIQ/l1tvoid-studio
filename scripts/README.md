# Apollo 11 vertical film

The isolated `video/apollo-11-tiktok` branch contains a Blender scene generator, Russian narration text, and a deterministic original music/subtitle generator. The branch-specific GitHub Actions workflow renders a 40-second, 24 fps vertical MP4 and publishes it as the `apollo11-tiktok` artifact. Nothing is merged into `main`.

To render manually, run the workflow from the Actions tab or push a commit to this branch.
